---
description: Draft the ongoing fee renewal consent for one arrangement. Never sends.
---

Run `npm run advice -- draft-consent --arrangement=<ref>`. It writes a draft to `drafts/` with the services for the coming year, the fee, the accounts, the reference day and the date the arrangement ends if not signed.

For a printable branded version of every AU consent, run `npm run docs -- consent-form`.

Tell the operator to check the draft against the licensee's own consent template before it goes. Nothing is sent from here.
