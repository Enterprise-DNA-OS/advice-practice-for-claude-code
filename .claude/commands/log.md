---
description: Write a file note against a client: a call, email, meeting or note.
---

Run `npm run advice -- log --client="<client>" --note="<what happened>" --kind=note|call|email|meeting --actor="<operator>"`.

Write the note the way the operator said it, tidied but not embellished. If the note records advice given, remind the operator that the advice file needs its scope and reasons (`/advice`).
