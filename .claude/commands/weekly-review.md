---
description: The Monday review: consents, reviews, pipeline, complaints and compliance, written up.
---

Run `npm run advice -- weekly-review --json`, plus `npm run advice -- fee-book`.

Write a one-page Monday note for the principal:
1. **Money at risk:** lapsed and closing consents with the fee amounts, by currency.
2. **Clients owed a review:** the overdue ones paying an ongoing fee.
3. **Advice pipeline:** what is stuck, and who has it.
4. **Complaints:** each open one and its deadline.
5. **Compliance:** the count by rule, and the three to fix first.

End with three actions for this week, each naming a person. Save it to `drafts/weekly-review-<date>.md`.
